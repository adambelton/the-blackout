# Brand Reference — The Blackout

This document defines the visual identity of The Blackout. It is the source of truth for colour, typography, and UI conventions across the platform.

---

## Colour Palette

| Name | Hex | Role |
|---|---|---|
| Umber | `#1F1A14` | Primary dark — text, dark backgrounds |
| Ivory | `#FDFAF4` | Primary light — default background |
| Forest | `#3A5432` | Hero green — hero backgrounds, primary brand colour |
| Sage | `#8FAE80` | Mid green — accents on dark backgrounds |
| Celadon | `#DDE4DC` | Light accent — pills, subtle fills, borders |
| Driftwood | `#9E8468` | Secondary text — subtitles, supporting copy |
| Stone | `#72726C` | Tertiary text — metadata, timestamps |

### Usage notes

- **Umber on Ivory** is the default light mode pairing
- **Ivory on Umber** is the default dark mode pairing
- **Ivory on Forest** is the hero pairing — use for featured broadcasts, hero sections, and anywhere the brand needs to make an impression
- **Sage** is for accent text on dark (Umber or Forest) backgrounds only
- **Celadon** is the light accent — pills, tags, and subtle surface fills on Ivory backgrounds
- **Driftwood** replaces grey for secondary text — it adds warmth without competing with the greens
- Never use pure black or pure white

---

## Typography

One typeface throughout: **DM Sans** (Google Fonts).

Three weights only:

| Weight | Usage |
|---|---|
| 300 (Light) | Display, headlines, card titles — the floating, considered voice |
| 400 (Regular) | Body text, supporting copy |
| 500 (Medium) | Labels, pills, UI controls, navigation |

### Type scale

| Role | Size | Weight | Tracking | Leading |
|---|---|---|---|---|
| Display | 36–40px | 300 | −0.04em | 1.1 |
| Headline | 20–24px | 300 | −0.03em | 1.3 |
| Card title | 16–18px | 300 | −0.03em | 1.2 |
| Body | 15px | 400 | 0 | 1.7 |
| UI / subtext | 13–14px | 400 | 0 | 1.5 |
| Label | 10–11px | 500 | 0.12em | — |

### Rules

- Labels are always uppercase with 0.12em letter spacing
- Never use weight 600 or 700 — they are too heavy for this system
- Body text should always be Umber on Ivory or Ivory on dark — never grey on white

## UI Conventions

- **Border radius** — 10–12px for cards, 8px for smaller components, 100px for pills
- **Border weight** — 0.5px throughout. Never 1px.
- **Shadows** — none. Depth is created through colour contrast, not shadows.
- **Spacing** — generous. The system breathes. Err toward more whitespace.
- **The forest card is the hero** — use it for featured broadcasts, landing sections, and anywhere the brand needs to make its strongest impression.

---

## Tone

The visual identity reflects the product's character:

- **Considered, not corporate.** Every element earns its place.
- **Literary, not academic.** Warm and human, not cold and institutional.
- **Quietly rebellious.** Against the blackout, against generic sports design. The restraint is the statement.
- **Japandi register.** Warm neutrals, natural greens, negative space. Nothing decorative that isn't also functional.
